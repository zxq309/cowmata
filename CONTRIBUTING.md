# Contributing / 贡献指南

Use a focused change with its data and validation scope. Keep raw farm data, credentials and generated experiment output out of commits. Run the documented demo and checks when executable behavior changes.

Every user-visible change updates `CHANGELOG.md` and both README latest-update summaries in the same commit. Use the actual maintenance date. Documentation-only updates do not silently bump model versions or rewrite historical release dates. Record software releases separately from dated main-branch maintenance.

涉及用户可见变化，同一提交更新 CHANGELOG 以及中英文 README 的最新更新摘要；写实际维护日期。纯文档更新不擅自改模型版本，不重写历史发布日期。实验报告同时说明数据范围、独立性、真值锚点和未验证内容。
