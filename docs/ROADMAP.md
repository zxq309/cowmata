# 路线图

## 当前：产犊实验优先

1. 持续完善标注协议与人工复核，保留行为标签和产犊真值的语义区别。
2. 识别仓独立迭代行为/事件模型，输出时间线与质量信息。
3. 决策仓已纳入温度与活动量模块；先核对时间、绑定、缺失数据与状态恢复。
4. 接入事件输出并制定融合策略，固定独立牛/胎次的开发、验证和测试划分。
5. 报告首次有效预警提前量、漏报、误报/牛/24h及有效观测覆盖，之后再评估部署。

## 后续任务

发情、妊娠状态和健康风险先在决策仓按模块建设。只有在团队、依赖、权限或发布节奏确实独立时再考虑分仓。
完整预警服务、前后端与牧场部署暂未交付；需要时优先在总体仓承担集成职责。
